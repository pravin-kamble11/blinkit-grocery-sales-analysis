# BlinkIT Grocery Sales Analysis | Power BI Dashboard

## 📊 1. Project Overview

This project is an **interactive Power BI dashboard developed to analyze BlinkIT grocery sales data** and generate meaningful business insights.

The project focuses on analyzing **sales performance, product categories, customer ratings, outlet characteristics, outlet locations, outlet sizes, and outlet types**.

The raw data was processed and transformed using **Power Query**, analyzed using **DAX**, and presented through interactive Power BI visualizations and KPIs.

The main purpose of the project is to transform raw grocery sales data into a **business-oriented analytical dashboard** that can help identify sales patterns, compare outlet performance, and understand product-level performance.

---

## 🎯 2. Business Objective

The primary objective of this project is to analyze grocery sales data and understand the factors influencing sales performance across different products and outlets.

The analysis aims to answer questions such as:

* What is the overall sales performance?
* Which product categories contribute the most to sales?
* Which outlet types generate higher sales?
* How does sales performance vary by outlet size?
* How does sales vary across different outlet locations?
* How do customer ratings vary across different item types?
* How has sales performance changed over outlet establishment years?
* Which product and outlet segments are performing better?

The dashboard provides an interactive way to explore these questions and support **data-driven business decision-making**.

## 📁 3. Dataset Information

The project uses the **BlinkIT Grocery Data** dataset provided in Excel format.

### Dataset Size

* **Records:** 8,523
* **Columns:** 12
* **Data Source:** Microsoft Excel

### Dataset Fields

| Field                     | Description                                     |
| ------------------------- | ----------------------------------------------- |
| Item Identifier           | Unique identifier for each grocery item         |
| Item Fat Content          | Classification of the item's fat content        |
| Item Type                 | Category or type of grocery item                |
| Item Weight               | Weight of the grocery item                      |
| Item Visibility           | Visibility percentage of the item in the outlet |
| Sales                     | Sales generated by the item                     |
| Rating                    | Customer rating for the item                    |
| Outlet Identifier         | Unique identifier for each outlet               |
| Outlet Establishment Year | Year in which the outlet was established        |
| Outlet Size               | Size classification of the outlet               |
| Outlet Location Type      | Tier classification of the outlet location      |
| Outlet Type               | Type/category of the grocery outlet             |

## 🧮 7. DAX Measures & Calculations

DAX was used to create dynamic measures for the dashboard and KPI calculations.

Examples of analytical calculations include:

* Total Sales
* Average Sales
* Number of Items
* Average Rating
* Sales comparisons across outlet types
* Sales analysis by outlet size and location
* Category-level sales analysis

Example DAX measure:

```DAX
Total Sales = SUM('BlinkIT Grocery Data'[Sales])
```

Using DAX measures allows the dashboard values to dynamically respond to filters and user selections.
