# BlinkIT Grocery Sales Analysis | Power BI Dashboard

## 📊 Project Overview

This project presents an **interactive Power BI dashboard for analyzing BlinkIT grocery sales data** and identifying key business insights across products, outlets, sales performance, customer ratings, and outlet characteristics.

The dashboard transforms raw grocery sales data into an interactive business intelligence solution that enables users to explore **sales trends, product performance, outlet performance, item characteristics, and customer ratings** through dynamic KPIs, charts, filters, and detailed tables.

The project demonstrates practical skills in **data analysis, data visualization, business intelligence, and Power BI dashboard development**.

---

## 🎯 Business Objective

The primary objective of this project is to analyze grocery sales data and answer important business questions such as:

* How are overall sales performing?
* Which product categories contribute most to sales?
* How does sales performance vary across outlet locations?
* Which outlet sizes generate higher sales?
* How have sales changed over the outlet establishment years?
* How do customer ratings vary across different item types?
* What is the relationship between product characteristics and sales performance?
* Which outlet types and locations show stronger performance?

---

## 📁 Dataset

The analysis is based on the **BlinkIT Grocery Data** dataset containing:

* **8,523 records**
* **12 attributes**

### Key Fields

| Field                     | Description                                |
| ------------------------- | ------------------------------------------ |
| Item Identifier           | Unique identifier for each item            |
| Item Fat Content          | Fat-content classification of the item     |
| Item Type                 | Category/type of grocery item              |
| Outlet Establishment Year | Year in which the outlet was established   |
| Outlet Identifier         | Unique outlet identifier                   |
| Outlet Location Type      | Tier classification of the outlet location |
| Outlet Size               | Size classification of the outlet          |
| Outlet Type               | Type of grocery outlet                     |
| Item Visibility           | Visibility of the item within the outlet   |
| Item Weight               | Weight of the item                         |
| Sales                     | Sales generated by the item                |
| Rating                    | Customer rating                            |

## 📈 Dashboard Features

The Power BI dashboard provides an interactive view of grocery sales performance through:

### KPI Overview

The dashboard highlights key performance indicators including:

* **Total Sales**
* **Average Sales**
* **Number of Items**
* **Average Rating**

### Sales Analysis

* Sales performance across outlet establishment years
* Sales distribution by outlet size
* Sales comparison across outlet location tiers
* Sales analysis across outlet types

### Product Analysis

* Item-type performance
* Item fat-content analysis
* Average rating by product category
* Product-level sales and performance analysis

### Outlet Analysis

* Outlet size comparison
* Outlet location analysis
* Outlet-type performance
* Outlet-level performance comparison

### Interactive Filters

Users can dynamically filter the dashboard by:

* Outlet Location Type
* Outlet Size
* Item Type
* Selected performance metrics

This allows users to explore the data from multiple business perspectives.

The dashboard is designed to help identify:

* High-performing product categories and item segments
